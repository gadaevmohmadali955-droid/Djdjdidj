# 🎮 BloxChat

Тёмная Roblox-стиль чат-рулетка с биометрической верификацией лица и возраста, голосовыми и видеозвонками, системой друзей и панелью администратора.

---

## 🚀 Как скачать APK через GitHub Actions

В репозитории настроен автоматический CI/CD воркфлоу (`.github/workflows/build.yml`), который собирает готовый APK-файл при каждом коммите или вручную:

1. Перейдите во вкладку **Actions** в верхней панели вашего репозитория на GitHub.
2. В списке слева выберите воркфлоу **Build Android APK**.
3. Нажмите кнопку **Run workflow** -> **Run workflow** (или откройте последний успешный запуск после пуша).
4. Дождитесь завершения сборки (зелёная галочка `build`).
5. Прокрутите страницу вниз до раздела **Artifacts** (Артефакты).
6. Нажмите на **BloxChat-Debug-APK** — архив с готовым `.apk` файлом скачается на ваш компьютер или телефон.
7. Распакуйте архив и установите `app-debug.apk` на Android-устройство!
